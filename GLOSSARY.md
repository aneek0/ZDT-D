# ZDT-D

Единая терминология ZDT-D для диагностики доступа, подбора стратегий и оценки их результата.

## Blockcheck

**Открытый baseline**:
Целевой запрос успешно проходит без обхода. Это результат пробы, а не основание прекратить проверку выбранных стратегий.
_Avoid_: отсутствие блокировки, нечего проверять

**Информационный прогон**:
Проверка выбранного набора стратегий при открытом baseline для сравнения их поведения, а не для подтверждения разблокировки цели. Стратегию можно применить только явным действием пользователя.
_Avoid_: пропуск проверки, поиск разблокировки

**Обрыв ответа в окне 16–20 КБ**:
Повторяющееся преждевременное завершение HTTPS-передачи в эталонном окне 12–36 КБ filter bytes с учётом TLS и заголовков. Это транспортная аномалия, а не любой короткий HTTP-ответ.
_Avoid_: TLS-блок ClientHello, блокировка маленькой страницы

**Volume-проба**:
Повторные HTTPS-запросы по одному TCP-соединению для проверки прохождения окна обрыва. Её диагностическое время не входит в скорость открытия страницы.
_Avoid_: замер скорости, проверка только HTTP-статуса

**Самая быстрая стратегия**:
Стратегия с минимальной медианой времени полного успешного HTTPS-запроса; диагностические volume-пробы в замер не входят. Неуспешные и неполные серии попыток не участвуют в ранжировании; baseline не считается стратегией.
_Avoid_: первая рабочая стратегия, лучшая попытка
